# Source context

Purpose: Map controller, worker, transfer, transport, and build modules.

- `extension.ts`: Host controller commands, policy and lifecycle ownership.
- `backend.ts`: Rootless OCI argv, runner and owned-container lifecycle.
- `worker.ts`: No-discovery Pi session and broker-only provider inside a phase worker.
- `transfer.ts`: Canonical candidate capture and human-approved immutable snapshots.
- `broker.ts`: Phase-bound host inference relay without tool execution.
- `adapter.ts`: Stream protocol adapter between workers and broker.
- `state.ts`: Atomic controller state and exclusive project lease.
- `lifecycle.ts`: Write-ahead container intent and identity-checked orphan removal.
- `lock.ts`: Reviewed image identity and embedded resource hashes.
- `probe.ts`: Real-image socket, namespace, mount, UID and resource-limit prerequisite checks.

- `transcript.ts`: Strict transcript union validation and broker-issued assistant replay identity.

- `worker-console.ts`: Show bounded inert worker output and submit human-authored lines through a disposable attach client.

- `review-screen.ts`: Present validated candidates and gate exact-byte approval behind complete human pagination.

- `panel-viewport.ts`: Bind focused panels to compositor-confirmed full-terminal overlay bounds.
