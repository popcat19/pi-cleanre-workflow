# Test context

Purpose: Map boundary regressions and opt-in real runtime checks.

- `boundaries.test.ts`: Transfer integrity, safe argv and prerequisite failures.
- `broker.test.ts`: Transport capability, budget, cancellation and terminal checks.
- `controller.test.ts`: Human command approval, configured reservation and real phase mounts.
- `packaged-runtime.test.ts`: Installed Pi process regression for reservation rejection and completion.
- `packaged-runtime.ts`: Offline extension fixture using the actual extension model registry.
- `lifecycle.test.ts`: Write-ahead ownership and OS lease exclusion/death recovery.
- `runtime.test.ts`: Real image inference, isolation probes and probe SIGKILL recovery.
- `transcript.test.ts`: Native replay identity and strict message union rejection.

- `tui.test.ts`: Verify inert worker rendering, attach cleanup, exact picker identity and complete human review gates.

- `panel-layout.ts`: Exercise installed Pi dock layout and overlay compositing without a real terminal.
